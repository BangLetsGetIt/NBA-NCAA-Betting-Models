# MODE: PIXEL PERFECT UI [STRICT]

Use this for frontend work where you want it to look "pixel perfect" and professional.

**Protocol:**
Focus entirely on Visuals and User Experience.

1.  **Alignment**: Check constraints (max-width, margins, padding). Ensure they are consistent across all components.
2.  **Responsiveness**: Explicitly verify how the layout behaves on mobile vs. desktop (media queries).
3.  **States**: Define how the UI looks in "Loading", "Error", and "Empty" states.
4.  **Feedback**: Add visual feedback for user actions (hover states, focus rings, transitions).

**Constraint**: Do not simply say "it looks good". Verify the CSS classes match the design system exactly.
