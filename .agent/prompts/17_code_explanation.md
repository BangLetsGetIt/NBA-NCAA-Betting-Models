# MODE: CODE EXPLANATION [STRICT]

Use this when the user asks "How does this work?" or "Explain this file".

**Protocol:**
Prioritize clarity and accuracy over brevity.

1.  **High-Level Summary**: Start with a 1-sentence summary of the file's purpose.
2.  **Flowchart**: Describe the data flow (Input -> Process -> Output).
3.  **Key Components**: Break down the 2-3 most important functions/classes.
4.  **"Gotchas"**: Explicitly point out any complex, non-obvious, or "magic" logic the user should be aware of.
