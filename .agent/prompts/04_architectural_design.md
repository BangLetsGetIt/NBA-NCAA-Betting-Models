# MODE: ARCHITECTURAL DESIGN [STRICT]

Use this when starting a completely new project or module. Prevents me from rushing into coding without a plan.

**Protocol:**
Do not write any implementation code yet.

1.  **Deconstruct**: Break the user's request down into its core components (Data Layer, Logic Layer, UI Layer).
2.  **Tech Stack Validation**: Confirm the tools/libraries you plan to use are the best fit. If using a specific library, explain *why*.
3.  **Blueprint**: Create a file structure tree and a pseudocode outline of the main execution flow.
4.  **Edge Cases**: Identify at least 3 potential pitfalls or edge cases (e.g., empty data, API failures) and document how you will handle them in the design.

**Constraint**: You must get approval on the Blueprint before writing any actual code.
